# 待辦清單（P0–P3）

_Updated: 2026-11-27。對應 [`roadmap.md`](roadmap.md) 第零、一節。完成一項就刪去或移到 roadmap 的證據欄。_

| 優先 | 意思 |
|---|---|
| **P0** | 正影響試用中的使用者或資料，盡快處理 |
| **P1** | M4 Go/No-go 之前必須完成 |
| **P2** | 試用及 pilot 期間應該改善，不阻擋 M4 |
| **P3** | 之後再做，或要先有 pilot 數據 |

每項開工前依 roadmap 第五節：先定合約及驗收條件，跨目錄的改動經 Integration。

## P1 — M4 之前

| # | 項目 | 範圍 | 備註 |
|---|---|---|---|
| P1-1 | **伺服器端執行案件規則** | Server、Shared Types、Case Content | 現時 `revealed_facts` 從未更新（沒有對應事件），一般選片指令不檢查片段是否在清單內，亦不檢查 `requires`／`forbidden_after`。目前靠 Wizard 自己記住。先定合約（spec §12、ADR-0002） |

| P1-3 | **rubric 分級描述** | Case Content（老師） | `rubric.json` 只有項目及滿分。需要每級描述、正反例及「未能評估」的規則，評分一致性才有意義 |
| P1-4 | **研究倫理文件** | Docs | 同意書、debrief、斷線揭露分級文案（ADR-0002）。M4 門檻表的必備項目 |

| P1-7 | **PR #19：有新版前端時提示重新載入** | 四個前端 | 與 #21 衝突，要重新同步及複審。可減少「部署後舊分頁仍在用舊版」的風險 |
